Method: no interpolation. The OAT is rounded up to the next whole degree, and an OAT below 0 °C uses the 0 °C row. A pressure altitude of 0 ft or below uses the 0 ft table (4.4.1); above 0 ft up to 250 ft uses the 250 ft table (4.4.2). Above 250 ft there is no table here. The 0 ft table is published in lb only, so its kg figures are converted (1 kg = 2.20462 lb).
